桌面 Markdown 渲染与 JDK 25

用户消息与 Agent 回答直接呈现 Markdown。参考 KZAgent 的渲染与表格布局，保留本项目 Material 界面风格；原文存储、服务 API、队列及停止语义保持原有行为。

展示行为

内容行为
正文支持标题、强调、删除线、嵌套列表、引用、只读任务列表和网页链接。正文与代码可选择复制。
代码代码块显示语言、语法高亮和复制按钮；长行可横向滚动。Mermaid 显示源码。
表格列宽按内容测量并限制在可读范围；单元格完整换行，超宽表格提供可拖动的独立横向滚动条。
图片支持 HTTPS、当前聊天工作目录内的相对路径、绝对路径、file: URL，包含 PNG/SVG。解析规范路径后检查工作目录边界，越界软链接、缺失文件与不支持的协议显示替代文字。
公式与脚注暂展示源码。预处理保护代码围栏、缩进代码、行内代码和链接目标，避免改变代码中的 $ 与 [^1]。
状态与摘要状态、提示和执行摘要继续显示纯文本。会话标题保留已有生成规则。

解析异步执行，相同正文复用解析状态；图片文件检查在 IO 协程执行。解析失败显示原文。图片相对路径按当前会话工作目录解析，切换目录后旧消息图片也按新目录解析，不增加历史目录快照。

现有服务迁移

新版本要求 Java 25 或更新版本。bridgectl 校验已配置 Java，旧版本或无法识别的版本会明确拒绝；不会自动改写已配置的 dev/prod 运行路径。

  1. 为目标机器准备 JDK 25，确认其 bin/java -version。
  2. 在计划升级目标环境时，将该环境 runtime.json 的 java 改为新 JVM 的绝对路径，保留机器人配置、模型目录与工作目录。
  3. 通过 bridgectl publish/deploy 发布、部署不可变快照。正式操作显式指定 --env prod。不修改 releases 内产物。

本次实现只构建并验收，不部署正式服务。旧式 build/install 运行实例必须先停止，再执行 installDist；不可变发布快照实例可与构建并行。

macOS 上已通过完整构建、核心与桌面离线测试、部署测试及 createDistributable。核心测试 275 项（8 项条件跳过），桌面测试 11 项；Python 部署测试 51 项（13 项平台跳过），均无失败。打包运行时为 Java 25.0.2。
